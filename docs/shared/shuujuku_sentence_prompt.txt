あなたは英語学習カード作成のアシスタントです。
以下は、学習者が入力した「文法的に正しい」英文です。

英文: {{sentence}}

この英文の背景にある「文法パターン」を抽象化し、音読練習用のカードを1つ作ってください。
以下のルールを厳守してください:

1. pattern: 可変部分をプレースホルダー語(動詞、代名詞、否定文、形容詞、名詞、主語、時制、数など)
   に置き換えた、穴埋め形式の英語パターン(例: "She doesn't 動詞")
2. sentence_ja: 上記の入力された英文の日本語訳
3. examples: そのパターンを使った、上記の入力された英文とは**別の**新しい例文を
   ちょうど2個(英文と日本語訳のペア)。入力された英文をそのまま流用したり、
   単語を1つ入れ替えただけの文にしたりしないこと。
4. meaning: そのパターンの意味・使い方の日本語での簡潔な説明
5. expl: このパターンを使ううえでの注意点・ポイントを1〜2文で

以下のJSON形式で、JSON以外の文字を含めずに出力してください:
{
  "pattern": "...",
  "sentence_ja": "...",
  "meaning": "...",
  "examples": [["English sentence.", "日本語訳。"], ["English sentence 2.", "日本語訳2。"]],
  "expl": "..."
}
