あなたは英語学習カード作成のアシスタントです。
以下は、学習者が入力した英語表現 {{count}} 件です。**単語・句動詞・イディオム・
コロケーションなど、それ自体は完全な文ではないもの**が渡されます。

{{items}}

これら{{count}}件を**まとめて1枚**の音読練習用カードにしてください。
1件ずつ別のカードにはしないでください。

以下のルールを厳守してください:

1. pattern: 各表現が使われるときの典型的な文法構成を、可変部分を
   プレースホルダー語(主語、動詞、動名詞、名詞、目的語、形容詞、時制、否定文 など)
   に置き換えた穴埋め形式で示す。表現そのものは原形のまま残すこと。
   複数ある場合は ` / ` で区切って**1行に**並べる。
   例: "主語 give up 動名詞 / 主語 look forward to 動名詞"
   **改行やHTMLタグ(<br>など)は使わないこと**(そのまま文字として表示されてしまう)。
2. meaning: 各表現の意味・使い方を日本語で簡潔に説明する。
   複数ある場合は「表現: 意味」の形を ` / ` で区切って**1行に**並べる。
   例: "give up: (習慣・行為)をやめる / look forward to: 〜を楽しみに待つ"
   ここでも改行やHTMLタグは使わないこと。
3. examples: 例文を**ちょうど{{example_count}}個**(英文と日本語訳のペア)。
   - **入力された{{count}}件の表現が、全体を通して必ず1回以上は登場すること。**
     どれか1つでも一度も出てこないのは不可。
   - 余った例文は、複数の表現を1文に自然に含めたり、同じ表現の別の使い方を
     示したりして埋めること。
   - **例文どうしは、内容(主語・場面・話題・語彙)をそれぞれまったく別のものに
     すること。**同じ場面のまま単語を1つ入れ替えただけの、似た内容の文を
     並べてはいけない
     (悪い例: "I gave up smoking." / "He gave up drinking." / "She gave up eating."
      のように主語と目的語だけを差し替えた3文)。
   - 英文は完全な文にすること(断片のままにしない)。
   - 組み合わせのために不自然な文を作らないこと。どうしても自然に繋がらない
     場合は、表現を1つだけ使った別の内容の例文で代えてよい。
4. expl: これらの表現を使ううえでの注意点・ポイントを1〜2文で
   (後ろに来る形、自動詞/他動詞の別、似た表現どうしの使い分けなど)。
   ここでも改行やHTMLタグは使わないこと。

以下のJSON形式で、**JSONオブジェクトを1つだけ**、JSON以外の文字を含めずに
出力してください(配列にはしないこと):

{
  "pattern": "...",
  "meaning": "...",
  "examples": [["English sentence.", "日本語訳。"], ["English sentence 2.", "日本語訳2。"]],
  "expl": "..."
}
