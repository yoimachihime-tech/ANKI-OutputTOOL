以下のルールを厳守してください:

1. pattern: **その表現を使うときの典型的な文法構成**を、可変部分を
   プレースホルダー語(主語、動詞、動名詞、名詞、目的語、形容詞、時制、否定文 など)
   に置き換えた穴埋め形式で示す。表現そのものは原形のまま残すこと。
   例: "give up" → "主語 give up 動名詞" / "look forward to" → "主語 look forward to 動名詞"
2. meaning: その表現の意味・使い方の日本語での簡潔な説明
3. examples: 上記のパターンに沿った例文を**ちょうど{{example_count}}個**
   (英文と日本語訳のペア)。次の構成にすること:
   - **最初の3つ**: その件の表現**だけ**を使った例文。
   - **残りの{{combo_count}}個**: その件の表現に加えて、下の
     「今回入力された表現の一覧」から**別の表現を1つ**選び、
     **両方を自然に1文へ含めた**例文。組み合わせる相手は毎回変えること。
     (残りが0個の場合は、最初の3つだけで合計3個になる)
   - **入力された表現を必ず各例文に含めること。**
   - **例文どうしは、文法構成は同じでも、内容(主語・場面・話題・語彙)は
     それぞれまったく別のものにすること。**同じ場面のまま単語を1つ入れ替えた
     だけの、似た内容の文を並べてはいけない
     (悪い例: "I gave up smoking." / "He gave up drinking." / "She gave up eating."
      のように主語と目的語だけを差し替えた3文)。
   - 英文は完全な文にすること(断片のままにしない)。
   - 組み合わせのために不自然な文を作らないこと。どうしても自然に繋がらない
     場合は、その表現だけを使った別の内容の例文で代えてよい。
4. expl: その表現を使ううえでの注意点・ポイントを1〜2文で
   (後ろに来る形、自動詞/他動詞の別、似た表現との違いなど)
