設定

このページの版: -

新しい端末でも、ふつうは何も入力する必要はありません。 「Googleにログイン」を押すと、APIキーやスプレッドシートIDが自動で設定されます (ログイン維持用 Worker から受け取ります。下の「起動時に自動で読み込む」を OFFにしている場合は、同期かDailyConversationタブを使った時点で設定されます)。 以下の欄は、自動で入らないときや、一時的に別の値を試したいときのためのものです。

APIキーはこのブラウザ内(localStorage)にのみ保存され、 Google以外のサーバーには送信されません。 共用の端末では使用後に「キーを消去」「TTSキーを消去」「ログアウト」を それぞれ実行してください。

「一覧を取得」を押すと、そのAPIキーで使えるモデルを取得してここに並べます (取得した一覧はこのブラウザに保存され、次回以降も出ます)。 一覧に無いモデル名を使いたいときは「直接入力…」を選んでください。

Gemini APIの使用状況

このブラウザから今日呼び出した回数です。分母(上限)は、上限に一度ぶつかったときに Googleが応答で教えてくれた値をそのまま覚えたもので、アプリ側に固定の数字は 持っていません。上限が変わっても、次に一度ぶつかった時点で自動で入れ替わります。 まだ一度もぶつかっていないモデルは分母を表示しません。

無料枠の1日あたりの上限は太平洋時間の深夜にリセットされます(日本時間では おおよそ午後4〜5時)。Googleはプロジェクト単位で数えるため、他の端末やブラウザから 同じキーを使っている場合、ここの回数は実際より少なく出ます。

設定すると、.apkg 出力時に例文の音声を自動で合成して埋め込みます。空欄のままなら 従来どおり音声無しの .apkg を出力します。

「自動調整」は、テスト再生と同じサンプル文で0dBを超えない(音割れしない)範囲に 音量ゲインを自動調整します(小さければ引き上げ、すでに音割れしている場合は 下げます)。

AIが指示に反して日本語の説明文などを混ぜて返してきた場合の保険用オプションです。 単語・AIに質問・DailyConversationタブの音声生成に効きます(習熟用は例文フィールドが 元々英文のみのため対象外です)。

スプレッドシート(DailyConversationタブ用)

「添削結果」シートの読み書きに使います。DailyConversationタブを使わない場合は 設定不要です。クライアントIDは秘密情報ではないため、他のAPIキーと違い そのまま保存しても問題ありません。

設定すると、ページを閉じてもGoogleログインが保たれます(空欄の場合は 従来どおり約1時間で切れ、そのつどログインし直しになります)。 セットアップ手順はリポジトリの worker/README.md を参照してください。 設定した場合、下のクライアントID欄は使いません(Workerから受け取ります)。

ただし、Google Cloud の OAuth 同意画面が「テスト」ステータスのままの場合、 Googleの仕様で7日ごとに1回はログインし直しが必要です (1時間ごとよりは大幅に長くなります)。しばらく使えていたのに急に ログインを求められた場合は、不具合ではなくこれが原因の可能性が高いです。

Google Cloud Console →「APIとサービス → 認証情報」で「OAuth クライアント ID」を 種類「ウェブ アプリケーション」で作成し、承認済みの JavaScript 生成元に このページのオリジン(例: https://yoimachihime-tech.github.io)を登録してください。 末尾が .apps.googleusercontent.com の文字列です。

通常は入力不要です。ログインすると Worker から自動で設定されます。 自動で入らない場合のみ、シートのURL /spreadsheets/d/ここ/edit の部分を貼ってください。

通常は入力不要です(ログイン時に自動設定されます)。

複数端末間の同期(任意)

単語・AIに質問・習熟用(音読)の3ストックを、上記と同じスプレッドシート内の 隠しタブへ保存し、別のPC・スマホと共有します。追加の同意やAPIキーは不要 (上のGoogleログイン設定をそのまま使います)。作業を終えて端末を切り替える 前に「🔄 今すぐ同期」を押してください。

ページを開いたときに、他の端末が保存した内容を自動で取り込みます (読み込むだけで、この端末の内容をシートへ書き戻すことはしません)。 同期ボタンの押し忘れで、古い状態のまま作業を始めてしまうのを防ぐためのものです。

バックアップ(書き出し / 読み込み)

3ストックの内容をJSONファイルとして手元に保存します。 この画面はデスクトップ版と違い、書き出した .apkg を自動保存していません。 ストックの項目が「Ankiに取り込む前の内容」を再現できる唯一のコピーなので、 「出力済みのカードを削除」を実行する前や、ブラウザのデータを消す前に書き出しておくことを 強く推奨します。

読み込みは現在の内容に足し合わせる方式です(既存の項目は消えません)。 削除済みの項目が含まれていた場合は、新しい項目として復元します (同じ内容が二重に見えることがありますが、一覧の「⚠ 重複」表示から選んで削除できます)。

        ① 英文・単語を入力してカードを作る

        1行に1件ずつ、複数まとめて入力できます(区切りは改行のみです。 カンマやスラッシュで1行に並べると、まとめて1枚のカードになってしまいます)。 入力の種類によって作り方が変わります。

        • 英文(例: I've been working here since 2020.) … その文法パターンを抽象化し、同じパターンを使った別の英文を2つ作ります。 入力した英文もカードにそのまま残るので、元の文脈と並べて音読できます。
        • 単語・句動詞など、それ自体は文ではないもの(例: give up) … 複数入力してもまとめて1枚のカードになり、 例文の数が語句の数に応じて増えます(1件なら3つ、2件なら4つ、 3件なら5つ…最大10まで)。入力したどの表現も、例文のどこかに必ず登場します。 例文どうしは内容(主語・場面・話題)がそれぞれ別のものになります。

        ⚠ 英文として入力したものは、文法的に正しい場合のみカードを生成します。 誤りが見つかった文はカードにせず、その理由を表示したうえで、 DailyConversationタブの入力欄に転記します。
        単語・句動詞として扱われるのは文末に「.」「!」「?」が無く、5語以内のものです (それ以外は英文として添削します)。短い英文を確実に添削させたいときは、 文末に「.」を付けてください。
        すべて大文字で入力された行は、カードを作るときに通常の表記へ自動で直します (直さないと大文字が理由で「誤り」になってしまうため)。固有名詞の大文字までは 復元できないので、直した結果は生成後のメッセージで確認してください。

        ① -2 他のタブから自動で追加されるカード

        上の入力欄のほかに、次の2つの操作からも自動的に追加されます。

        • 「AIに質問」タブで質問を送信したとき … その質問の背景にある 文法パターンを音読練習用にまとめたカードが、3問の練習問題とは別に 4問目として追加されます。
        • 「DailyConversation」タブで英文を添削させたとき … 添削で 見つかった誤りごとに、その背景にある文法パターンのカードが追加されます (カテゴリが「誤りなし」の文は、抽出すべき誤りが無いため対象外です)。
