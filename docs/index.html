ANKI出力ツール Web版

設定

新しい端末でも、ふつうは何も入力する必要はありません。 「Googleにログイン」を押すと、APIキーやスプレッドシートIDが自動で設定されます (ログイン維持用 Worker から受け取ります)。以下の欄は、自動で入らないときや、 一時的に別の値を試したいときのためのものです。

APIキーはこのブラウザ内(localStorage)にのみ保存され、 Google以外のサーバーには送信されません。 共用の端末では使用後に「キーを消去」してください。

設定すると、.apkg 出力時に例文の音声を自動で合成して埋め込みます。空欄のままなら 従来どおり音声無しの .apkg を出力します。

「自動調整」は、テスト再生と同じサンプル文で0dBを超えない(音割れしない)範囲まで 自動的に音量ゲインを引き上げます。

AIが指示に反して日本語の説明文などを混ぜて返してきた場合の保険用オプションです。 単語・AIに質問・DailyConversationタブの音声生成に効きます(習熟用は例文フィールドが 元々英文のみのため対象外です)。

スプレッドシート(DailyConversationタブ用)

「添削結果」シートの読み書きに使います。DailyConversationタブを使わない場合は 設定不要です。クライアントIDは秘密情報ではないため、他のAPIキーと違い そのまま保存しても問題ありません。

設定すると、ページを閉じてもGoogleログインが保たれます(空欄の場合は 従来どおり約1時間で切れ、そのつどログインし直しになります)。 セットアップ手順はリポジトリの worker/README.md を参照してください。 設定した場合、下のクライアントID欄は使いません(Workerから受け取ります)。

Google Cloud Console →「APIとサービス → 認証情報」で「OAuth クライアント ID」を 種類「ウェブ アプリケーション」で作成し、承認済みの JavaScript 生成元に このページのオリジン(例: https://yoimachihime-tech.github.io)を登録してください。 末尾が .apps.googleusercontent.com の文字列です。

通常は入力不要です。ログインすると Worker から自動で設定されます。 自動で入らない場合のみ、シートのURL /spreadsheets/d/ここ/edit の部分を貼ってください。

通常は入力不要です(ログイン時に自動設定されます)。

複数端末間の同期(任意)

単語・AIに質問・習熟用(音読)の3ストックを、上記と同じスプレッドシート内の 隠しタブへ保存し、別のPC・スマホと共有します。追加の同意やAPIキーは不要 (上のGoogleログイン設定をそのまま使います)。作業を終えて端末を切り替える 前に「🔄 今すぐ同期」を押してください。

ページを開いたときに、他の端末が保存した内容を自動で取り込みます (読み込むだけで、この端末の内容をシートへ書き戻すことはしません)。 同期ボタンの押し忘れで、古い状態のまま作業を始めてしまうのを防ぐためのものです。

バックアップ(書き出し / 読み込み)

3ストックの内容をJSONファイルとして手元に保存します。 この画面はデスクトップ版と違い、書き出した .apkg を自動保存していません。 ストックの項目が「Ankiに取り込む前の内容」を再現できる唯一のコピーなので、 「出力済みを削除」を実行する前や、ブラウザのデータを消す前に書き出しておくことを 強く推奨します。

読み込みは現在の内容に足し合わせる方式です(既存の項目は消えません)。 削除済みの項目が含まれていた場合は、新しい項目として復元します (同じ内容が二重に見えることがありますが、一覧の「⚠ 重複」表示から選んで削除できます)。

① 単語を入力

1行に1件、「単語 | 文脈」の形式で入力します。文脈は省略可で、完全な文である必要も ありません(句動詞や単語の組み合わせだけでも構いません)。

② 生成結果

生成したカードはこのブラウザに保存され、再訪しても残ります。 不要なものは選んで削除できます。一度「.apkg をダウンロード」した項目には 「✓ 出力済み」の印が付き、次回以降の出力対象から自動的に外れます (カード自体は削除されません)。

    文法に関する質問やお題を入力すると、AIが出題形式の異なる練習問題を3問 (選択問題・誤り訂正問題・記述式など)作成します。あわせて、同じ質問の 背景にある文法パターンを音読練習用にまとめた4問目が「習熟用(音読)」 タブへ自動的に追加されます。
