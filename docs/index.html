ANKI出力ツール Web版

設定

APIキーはこのブラウザ内(localStorage)にのみ保存され、サーバーには送信されません。 共用の端末では使用後に「キーを消去」してください。

設定すると、.apkg 出力時に例文の音声を自動で合成して埋め込みます。空欄のままなら 従来どおり音声無しの .apkg を出力します。

「自動調整」は、テスト再生と同じサンプル文で0dBを超えない(音割れしない)範囲まで 自動的に音量ゲインを引き上げます。

AIが指示に反して日本語の説明文などを混ぜて返してきた場合の保険用オプションです。 単語・AIに質問・DailyConversationタブの音声生成に効きます(習熟用は例文フィールドが 元々英文のみのため対象外です)。

スプレッドシート(DailyConversationタブ用)

「添削結果」シートの読み書きに使います。DailyConversationタブを使わない場合は 設定不要です。クライアントIDは秘密情報ではないため、他のAPIキーと違い そのまま保存しても問題ありません。

Google Cloud Console →「APIとサービス → 認証情報」で「OAuth クライアント ID」を 種類「ウェブ アプリケーション」で作成し、承認済みの JavaScript 生成元に このページのオリジン(例: https://yoimachihime-tech.github.io)を登録してください。 末尾が .apps.googleusercontent.com の文字列です。

シートのURL /spreadsheets/d/ここ/edit の部分です。

複数端末間の同期(任意)

単語・AIに質問・習熟用(音読)の3ストックを、上記と同じスプレッドシート内の 隠しタブへ保存し、別のPC・スマホと共有します。追加の同意やAPIキーは不要 (上のGoogleログイン設定をそのまま使います)。同期は自動では行われないため、 端末を切り替える前後に押してください。

① 単語を入力

1行に1件、「単語 | 文脈」の形式で入力します。文脈は省略可で、完全な文である必要も ありません(句動詞や単語の組み合わせだけでも構いません)。

② 生成結果

生成したカードはこのブラウザに保存され、再訪しても残ります。 不要なものは選んで削除できます。一度「.apkg をダウンロード」した項目には 「✓ 出力済み」の印が付き、次回以降の出力対象から自動的に外れます (カード自体は削除されません)。

まだカードがありません。

    ③ Ankiに取り込む

    .apkg をダウンロードし、AnkiMobile / AnkiDroid / デスクトップ版Ankiで開いてください。 同じ単語のカードは既存のものが更新されるだけなので、学習履歴は失われません。 ⚙設定でTTS APIキーを設定していれば、例文の音声も自動で合成して埋め込みます。 対象は②の一覧のうちまだ出力していないカードだけです。

    ① 質問・お題を入力

    文法に関する質問やお題を入力すると、AIが出題形式の異なる練習問題を3問 (選択問題・誤り訂正問題・記述式など)作成します。あわせて、同じ質問の 背景にある文法パターンを音読練習用にまとめた4問目が「習熟用(音読)」 タブへ自動的に追加されます。

    ② 生成結果

    生成したカードはこのブラウザに保存され、再訪しても残ります。 同じ質問を複数回試した場合は重複として警告表示されます。一度「.apkg を ダウンロード」した項目には「✓ 出力済み」の印が付き、次回以降の出力対象 から自動的に外れます(カード自体は削除されません)。

    まだカードがありません。

      生成したカードはこのブラウザに保存され、再訪しても残ります。 同じ質問から生成した場合は重複として警告表示されます。

        ③ Ankiに取り込む

        .apkg をダウンロードし、AnkiMobile / AnkiDroid / デスクトップ版Ankiで開いてください。 出力した内容はこの一覧から取り除かれます(番号の重複を避けるため、出力するたびに 続き番号を採番します)。 ⚙設定でTTS APIキーを設定していれば、各例文の音声も自動で合成して埋め込みます。

        🔒 このタブは「添削結果」スプレッドシートを直接読み書きするため、Googleへの ログインが必要です。画面右上のヘッダーにある「Googleにログイン」から ログインしてください(事前に⚙設定でクライアントID・スプレッドシートID・ シート名の設定も必要です)。

        ① 英文を入力してAIに添削させる

        複数文・複数段落をまとめて入力できます(AIが文ごとに分割して添削します)。 添削結果はシートに新規行として追記され、続けて②の一覧が更新されます。 Googleフォーム経由で追加された行もそのまま②に出てきます。

        ② シート上の未出力行

        「Anki出力済み」列が空の行を表示します。ここに出ているものが③の出力対象です。 重複などで出力したくない行は選んで「一覧から除外」できます(シート自体は 変更されず、この端末でのみ非表示になります)。③で一度.apkgに含めた行には 「✓ 出力済み」の印が付きます(③の「Anki出力済みにする」チェックをOFFに していた場合でも、このブラウザ内には記録されます)。

        まだ読み込んでいません。

          ③ Ankiに取り込む

          .apkg をダウンロードし、AnkiMobile / AnkiDroid / デスクトップ版Ankiで開いてください。 カテゴリが「誤りなし」の行と、IDが重複している行は出力対象から除かれます。 ⚙設定でTTS APIキーを設定していれば、添削後の文と類似表現の音声も自動で 合成して埋め込みます。
