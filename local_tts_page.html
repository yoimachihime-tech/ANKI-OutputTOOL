apkgにTTS音声を付ける

このページはお使いのPC上のツールが表示しています(http://127.0.0.1:8765)。 音声の生成・apkgの書き換えはすべてPC側で行われます。

① apkgを読み込む

Ankiから書き出した .apkg、または別の場所で作った .apkg を選びます。

② 音声を付けるフィールドを選ぶ

①で .apkg を読み込むと、ここにフィールドの一覧が出ます。

フィールドごとに「中身のある件数」とサンプルを表示しています。 日本語のフィールドやラベル用のフィールドを選ばないよう、サンプルを見て確認してください。 「日本語あり」の印が付いたフィールドは、英語の音声で日本語を読み上げてしまうので、 選ぶ場合は③の「日本語を含む文を除外する」をONにしてください。 複数のノートタイプ・複数のフィールドをまとめて指定できます。

③ 音声とオプション

APIキーは config.json の api_key を使います。

APIキーは config.json の gemini_api_key を使います。 1フィールドにつき Gemini API を1回呼びます(2文以上あるフィールドは、 「文ごとにタグを分ける」がONか「文と文の間隔」が0より大きいと、文の数だけ呼びます)。 MP3 への変換に lameenc を使います。

「文ごとにタグを分ける」がONだと、2文以上あるフィールドには音声が文の数だけ付き、 Ankiの再生ボタンもその数だけ並びます。1つにまとめたい場合はこれをOFFにしてください (「文と文の間隔」の分だけ無音を挟んで1つの音声にします)。 既に作ってしまった分を直すときは、右の「音声が2つ以上あるフィールドだけ 作り直す」を使うと、該当分だけをやり直せます(全部作り直す必要はありません)。

APIキーは config.json のものを使います(この画面には出しません)。 保存した設定は PC版(ANKI出力ツール)とも共通です。

④ 実行

まず「件数を数える」で対象とAPI呼び出し回数の見積もりを確認してください (「TTSを生成する」を押したときにも、同じ見積もりを確認してから始めます)。

.apkgをダウンロード

割り当ての上限などで途中で止まった場合も、そこまでの分は書き出されます。 翌日などに「TTSを生成する」を押し直すと、音声が入ったフィールドは自動で飛ばして 続きから進みます(このツールを終了してしまった場合は、書き出した .apkg を ①で読み込み直せば同じように続きから再開できます)。

⑤ カードテンプレートの調整

このapkgのテンプレートには {{tts ...}} が 0 個入っています。これは Anki本体が端末の音声で読み上げるためのタグで、 [sound:] が無くても再生ボタンが表示されます。 このツールが埋め込むCloud TTSの音声と並ぶため、 再生ボタンが2つ出ます。 取り除くとCloud TTSの音声だけになり、ボタンは1つになります (ノートの中身・音声には触りません。テンプレートだけを書き換えます)。

.apkgをダウンロード

ツールの終了

このツールは画面を閉じても裏で動き続けます(黒い画面は出しません)。 生成中に画面を閉じても生成は続き、もう一度このページを開けば進み具合を見られます。 使い終わったら下のボタンで終了してください(生成中は終了できません。先にキャンセルしてください)。 終了後もこのページは残りますが、操作しても反応しなくなります。
